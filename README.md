# Dexterous Hand / GM6020 夹爪固件

基于 **达妙 DM-MC-Board02（STM32H723VGT6）** 的 GM6020 腕部/夹爪旋转控制固件。

- **1 kHz** 角度-速度双闭环电流控制（TIM1 更新中断）
- FDCAN **1 Mbps**，GM6020 反馈 `0x205`，电流指令 `0x1FE`
- 速度反馈在 FDCAN 接收回调里做 Kalman 滤波
- USB CDC + **VOFA+**（JustFloat，6 通道，100 Hz）实时遥测
- PA15 按键启动测试序列，运行中再按一次立即急停

主工程在 `Gripper_GM6020/`，其余目录是开发板例程和参考工程。

---

## 硬件

| 项目 | 型号/参数 |
|------|-----------|
| 开发板 | 达妙 DM-MC-Board02（STM32H723VGT6，HSE 24 MHz，SYSCLK 480 MHz） |
| 电机 | GM6020，额定 24 V，CAN 固定 1 Mbps |
| 调试 | ST-Link → SWDIO / SWCLK / GND |
| 供电 | 板子 USB-C（5 V）或 24 V 输入；电机 24 V 独立供电 |
| 遥测 | USB-C → 电脑，VOFA+ |

### 电机拨码（必须）

| 位 | 设置 | 含义 |
|----|------|------|
| 1 | **ON** | ID bit0 = 1 |
| 2 | OFF | ID bit1 = 0 |
| 3 | OFF | ID bit2 = 0 |
| 4 | **ON** | 接入 120 Ω 终端电阻 |

→ 电机 ID = 1，反馈帧 `0x205`。上电后电机绿灯应**每秒闪 1 次**；闪 3 次说明 ID=3，代码收不到反馈。

### CAN 接线

| 接口 | 引脚 |
|------|------|
| 板载 2 芯 CAN | pin1 = CAN_L，pin2 = CAN_H |
| 板载 4 芯 CAN | pin1 = VCC，pin2 = GND，pin3 = CAN_H，pin4 = CAN_L |
| GM6020 CAN 线 | 红 = CAN_H（A），黑 = CAN_L（B） |

注意事项：

- 达妙和大疆的 4 芯 XT30 线序**相反**，直通线会把 H/L 接反；按 H/L 标签单独接线。
- 2 芯 CAN 口没有 GND，控制板 GND 必须和电机 24 V 电源 GND **共地**。
- 电机已独立供电时，**不要**把板子的 VCC/24 V 输出接到电机 VCC。
- 板载 CAN 收发器是 5 V 供电；只用 ST-Link 的 3.3 V 不能通信，需要 USB-C 或 24 V 给板子供电。

## 快速开始

1. 按上表设置电机拨码，**断电重上电**，确认绿灯每秒闪 1 次。
2. 接好 CAN_H/CAN_L/GND、电机 24 V，并确认控制板与电机电源共地。
3. USB-C 接电脑，ST-Link 接 SWDIO/SWCLK/GND（板子已 USB 供电时不要再接 3V3）。
4. 用 Keil 打开 `Gripper_GM6020/MDK-ARM/CtrBoard-H7_ALL.uvprojx`，编译并下载，看到 `Programming Done / Verify OK`。
5. 打开 VOFA+，串口选对应 COM 口，波特率任意（USB CDC），数据格式选 **JustFloat**，打开串口。
6. 右键波形图 → 勾选通道 0~5（VOFA+ 1.3.x 不支持拖拽绑定）。
7. 按一次 PA15，电机执行 **90° → -90° → 0°**，每个位置停稳后保持 2 秒。

## 控制结构

```
目标角度 ──→ [角度环 P + 速度阻尼] ──→ 目标速度 ──→ [速度环 PI] ──→ 电流 ──→ GM6020
                 ↑                                      ↑
            angle_unwrap                          Kalman 滤波速度
```

- **TIM1 更新中断 1 kHz**：状态机、保护、双环 PID、CAN 发送都在这里。
- **FDCAN 接收回调**：解析 `0x205`，更新角度/转速/电流/温度，并对转速做一维 Kalman 滤波。
- **GripperTask**：1 ms 周期消费按键计数，10 ms 发送一次 6 通道遥测。
- **KeyTask**：10 ms 扫描 PA15（100 ms 消抖），每次有效按键翻转蜂鸣器，并累加按键计数。
- 上电时 KeyTask 把板载 WS2812 设为绿色，仅作运行指示，不表示控制状态。

## 参数（当前带载整定值）

### 速度环

| 参数 | 值 | 说明 |
|------|-----|------|
| Kp | 3000 | mA / rps |
| Ki | 3 | 积分很慢，主要靠 P + 前馈 |
| Kd | 0.3 | 微分作用于实测速度 |
| 积分限幅 | 200 | |
| 输出限幅 | 2000 mA | |
| 摩擦前馈 | 400 mA | 0.1 rps 以下线性淡出 |
| 电流斜率 | 10 A/s | 抑制启动冲击 |

### 角度环

| 参数 | 值 | 说明 |
|------|-----|------|
| Kp | 0.1389 | **rps / 度** |
| Ki / Kd | 0 / 0 | 纯 P + 速度阻尼 |
| 速度阻尼 | 0.5 | 速度指令减去 0.5 × 实测 rps |
| 输出限幅 | 0.3 rps | 108 °/s，带载首测值 |
| 死区 | 0.5° | 到位后不再修正 |
| 速度指令斜率 | 3 rps/s | 防止反向阶跃 |

> **单位换算**：设计文档中的角度环 Kp=50 是按“弧度误差 → rad/s”写的，换算到本代码（度误差 → rps）是 `50 / 360 ≈ 0.1389`。不要直接把 50 填进来，否则环路会变成满速开关控制。

### 保护

| 保护 | 阈值 | 动作 |
|------|------|------|
| 电流限幅 | 2000 mA | 持续限幅 |
| 角度限位 | ±180° | 禁止继续往限位方向转 |
| 堵转 | 指令 >0.03 rps 且实测 <0.03 rps 持续 1000 ms | 锁存 ST_STALL，断流，需重新按键 |
| 过温 | 80 °C | 断流 |
| 通信看门狗 | 500 ms 无反馈 | 进入 ST_FAULT，反馈恢复后自动回到 RUN |

## 状态机与按键

| 状态值 | 名称 | 行为 |
|--------|------|------|
| 0 | IDLE | 空闲，电流 0 |
| 1 | RUN | 执行测试序列 |
| 2 | FAULT | 通信丢失，电流 0，反馈恢复后自动恢复 |
| 3 | STALL | 堵转锁存，电流 0，按一次 PA15 重试 |

按键行为：

- **IDLE / STALL 下按一次**：从 90° 开始执行序列。
- **RUN 下再按一次**：立即急停（回 IDLE，电流 0）。
- 蜂鸣器是“开/关”翻转，不是单次蜂鸣。

## 测试序列

```
0° ──→ +90° ──停稳──保持 2 s──→ -90° ──停稳──保持 2 s──→ 0° ──停稳──保持 2 s──→ IDLE
```

- 到位判据：`|误差| < 1°` 且 `|速度| < 0.05 rps`。
- 如果一直不到位，最多等 `步进时间 + 2 s 停留 + 6 s 超时` 后强制进入下一步；真正的堵转由堵转保护先切断。
- 序列结束后进入 **IDLE，电流归零、没有保持力矩**。带重力负载时负载会自由下落；需要位置保持请扩展一个 HOLD 状态。

## VOFA+ 遥测

格式：6 个 little-endian `float32` + 帧尾 `00 00 80 7F`，每 10 ms 一帧（100 Hz）。

| 通道 | 变量 | 含义 | 单位/范围 |
|------|------|------|-----------|
| 0 | `st` | 状态 | 0=IDLE，1=RUN，2=FAULT，3=STALL |
| 1 | `target_angle_deg` | 目标角度 | ° |
| 2 | `gm6020.angle_unwrap` | 实际角度（多圈展开） | ° |
| 3 | `target_omega_rps` | 目标速度 | rps |
| 4 | `gm6020.speed_rps` | 实际速度（Kalman 滤波） | rps |
| 5 | `cmd_ma` | 电流指令 | mA（±2000） |

VOFA+ 1.3.10：右键波形图 → 数据 → 勾选通道；右侧数据栏的数字也可以直接观察，`I0` 比波形更直观。

## 调试经验

- **I2 恒为 0**：没有收到 `0x205`。先看电机绿灯闪几下（ID 必须为 1），再查 H/L、板子 5 V、共地。
- **低速推不动、I0=3**：速度环在低目标速度下电流不足。先看 I5：只有几百 mA 就堵转 → 提高 `KP_OMEGA` 或 `FRICTION_FF_MA`；I5 到 2000 mA 还不动 → 负载超过约 1.4 N·m。
- **到位置晃动**：角度环增益过大或缺少阻尼。本代码用 `KP_ANGLE=0.1389` + `ANGLE_DAMPING=0.5` + 0.5° 死区整定；如果换负载后仍晃，先把 `KP_ANGLE` 降到 0.08，或把阻尼加到 0.8。
- **启动时绿灯闪一下/板子复位**：多为电机启动电流在共用地上造成的地弹。先加粗/缩短地线，让电机电流直接回电源负极；代码侧已有 10 A/s 电流斜率限制。
